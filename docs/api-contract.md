# API contract v1

The canonical project import contract is generated from
`packages/contracts/src/project.ts` into
`contracts/project-import.v1.schema.json`. Its SHA-256 sidecar is generated by
`npm run contracts:generate`.

Browser requests use the signed `training_session` cookie, exact
`TRAINING_WEB_ORIGIN`, and the in-memory CSRF token. MCP requests use
`Authorization: Bearer` with `TRAINING_API_MCP_TOKEN`.

Mutations include `expectedRevision`. A stale revision returns `409` with
`REVISION_CONFLICT` and `currentRevision`. Images are validated by bytes,
stored below `data/assets`, and represented in project data only by `AssetRef`.
